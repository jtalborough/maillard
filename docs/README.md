## What is Maillard?

Maillard is a standalone AI-powered coffee roasting control system for the Kaleido M10 roaster. It provides:

- **Direct roaster control** via WebSocket
- **AI integration** via Model Context Protocol (MCP)
- **Coffee inventory** management
- **Profile generation** and execution
- **Real-time monitoring** with RoR calculation
- **Post-roast analysis** and improvement suggestions
